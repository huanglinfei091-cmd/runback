# Public Alpha Distribution Report

Date: 2026-09-08

## Goal

Increase opt-in discovery of RunBack without sending bulk promotional comments to unrelated
users or repositories. The direct-outreach cap remains unchanged; public distribution is a
single announcement that people can choose to open or ignore.

## Published surface

- Public repository: https://github.com/huanglinfei091-cmd/runback
- Public prerelease: https://github.com/huanglinfei091-cmd/runback/releases/tag/v0.1.0-alpha
- GitHub Discussions enabled: yes
- Alpha announcement: https://github.com/huanglinfei091-cmd/runback/discussions/1
- Discussion category: Announcements

The announcement includes the Linux amd64 installation path, `runback doctor`, Direct URL
command, current compatibility boundary, truthful result vocabulary, Werkzeug evidence and a
request for public failed-run URLs. It asks users not to post tokens, secrets, cookies, private
source, complete private logs or credentials.

## Prepared community posts

The repository contains channel-specific drafts for later publication:

- `docs/launch/SHOW_HN.md`
- `docs/launch/REDDIT_DEVOPS.md`
- `docs/launch/DEV_TO.md`

They use the same verified facts but are written for each audience. They have not been reported
as published: Hacker News, Reddit and DEV Community require their own authenticated account and
submission step. No login, account creation or credential transfer was attempted.

## Measurement boundary

Potential reach is not a tester count. Repository views, post impressions, reactions, release
downloads and stars do not become user-validation evidence. A real tester is recorded only
after a person reports an actual RunBack invocation or equivalent concrete evidence.

Current external-user state remains `USER_VALIDATION_PENDING` until such evidence exists.
