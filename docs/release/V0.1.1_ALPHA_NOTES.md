# RunBack v0.1.1-alpha

RunBack turns one completed failed GitHub Actions run URL into a local replay and reports
`SAME_FAILURE` only when the remote and local structured evidence agrees.

This Alpha feedback release improves first-run installation and adds two retained compatibility
cases without changing the frozen Resolver, ActExecutor, session flow, or Matcher standard.

## Changes

- Add a checksum-verifying Linux amd64 release installer that writes to `~/.local/bin` and
  does not require Go or sudo.
- Expand `runback doctor` with actionable `Problem`, `Cause` and `Next` output for missing
  tools, Docker daemon access, GitHub API access, replay workspace, disk space, PATH and
  Docker networking.
- Parse standard Pyright diagnostics as exact file, line, diagnostic code and message evidence.
- Parse standard Go test failures as exact test, source file, line and message evidence.
- Normalize only RunBack-owned `/tmp/rb/<short-id>/workspace/` prefixes before evidence
  comparison.
- Add Fresh Case D and E evidence, preserving their first unsuccessful results and final
  strict `SAME_FAILURE` results.
- Add a copyable Werkzeug demo and distinguish it from a user's own failed run.

The Matcher threshold was not lowered. A nonzero exit code still does not prove reproduction.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/huanglinfei091-cmd/runback/main/scripts/install-release.sh | bash
export PATH="$HOME/.local/bin:$PATH"
runback doctor
```

The installer verifies the published `SHA256SUMS` file before atomically replacing the
user-owned binary.

## Retained real cases

- Flask: `SAME_FAILURE`
- Click: `SAME_FAILURE`, then `FULL_JOB_PASSED` after the source fix
- Werkzeug Case C: Direct URL `SAME_FAILURE`, remote/local/matched `1/1/1`
- Ramose Case D: first `REPLAY_BLOCKED`, final Pyright `SAME_FAILURE` `1/1/1`
- Aiden Firmware Case E: first `INSUFFICIENT_EVIDENCE`, final Go test
  `SAME_FAILURE` `1/1/1`

These five retained cases are evidence, not a compatibility percentage.

## Scope

The release targets public GitHub.com repositories, completed failed Ubuntu jobs, Linux amd64,
and ordinary Python, JavaScript/TypeScript and Go workflows that act can execute. Private
repositories, GitHub Enterprise, Windows/macOS/self-hosted runners, services, job containers,
repository-local actions, reusable job workflows and secret-dependent replay paths remain
outside the Alpha scope.

External user validation remains `USER_VALIDATION_PENDING`. No install, invocation, verdict,
TTFR or debugging-session evidence has yet been reported by an unrelated user.
